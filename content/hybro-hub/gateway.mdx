# Gateway

The `hybro-hub` package includes `HybroGateway`, an async Python client for the hosted Hybro Gateway API.

> The Gateway client is separate from the local Hub relay. Use it to discover and call cloud agents from code.

## Create a client

```python
from hybro_hub import HybroGateway

gw = HybroGateway(api_key="hybro_...")
```

Prefer the async context manager so the underlying HTTP client closes automatically:

```python
async with HybroGateway(api_key="hybro_...") as gw:
    ...
```

Constructor options:

```python
HybroGateway(
    api_key: str,
    base_url: str = "https://api.hybro.ai/api/v1",
    *,
    timeout: float = 120.0,
    client: httpx.AsyncClient | None = None,
)
```

## Discover agents

```python
agents = await gw.discover("data analysis", limit=5)

for agent in agents:
    print(agent.agent_id, agent.match_score, agent.agent_card.get("name"))
```

## Send a message

```python
result = await gw.send(agents[0].agent_id, "Analyze this dataset")
print(result)
```

Reuse a `context_id` for multiple turns:

```python
await gw.send(agent_id, "My name is Alice", context_id="conversation-1")
await gw.send(agent_id, "What is my name?", context_id="conversation-1")
```

## Stream a response

```python
async for event in gw.stream(agent_id, "Write a short report"):
    if event.is_error:
        print(f"Error: {event.data}")
        break
    print(event.data)
```

## Fetch an Agent Card

```python
card = await gw.get_card(agent_id)
print(card["agent_card"]["name"])
```

## Error handling

```python
from hybro_hub import (
    AccessDeniedError,
    AgentCommunicationError,
    AgentNotFoundError,
    AuthError,
    GatewayError,
    RateLimitError,
)

try:
    result = await gw.send(agent_id, "Hello")
except AuthError:
    print("Invalid API key")
except AccessDeniedError:
    print("No access to this agent")
except AgentNotFoundError:
    print("Agent not found or inactive")
except RateLimitError as error:
    print(f"Retry after {error.retry_after}s")
except AgentCommunicationError:
    print("The upstream agent failed")
except GatewayError as error:
    print(error)
```

| Exception | HTTP status |
| --- | ---: |
| `AuthError` | 401 |
| `AccessDeniedError` | 403 |
| `AgentNotFoundError` | 404 |
| `RateLimitError` | 429 |
| `AgentCommunicationError` | 502 |
| `GatewayError` | any |

## Full example

```python
import asyncio
from hybro_hub import HybroGateway

async def main():
    async with HybroGateway(api_key="hybro_...") as gateway:
        agents = await gateway.discover("legal contract review", limit=3)
        async for event in gateway.stream(
            agents[0].agent_id,
            "Review this NDA",
            context_id="nda-review",
        ):
            print(event.data)

asyncio.run(main())
```
