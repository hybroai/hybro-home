# Installation

## Requirements

- Python 3.11 or newer
- A Hybro account and API key when connecting to the hosted `api.hybro.ai` relay
- The runtime required by any local adapter you plan to launch, such as Ollama or a coding-agent CLI

## Install

```bash
pip install hybro-hub
```

`a2a-adapter` and `a2a-sdk` are core dependencies, so no extra is required to use `hybro-hub agent start`.

Verify the installation:

```bash
hybro-hub --version
```

## Get an API key

Open [hybro.ai/d/discovery-api-keys](https://hybro.ai/d/discovery-api-keys), generate a key, and copy the value beginning with `hybro_`.

Start the daemon once with the key:

```bash
hybro-hub start --api-key hybro_your_key_here
```

The key is saved to `~/.hybro/config.yaml`, unless `cloud.api_key` there is already an environment reference such as `${HYBRO_API_KEY}`. Precedence is `--api-key`, then `HYBRO_API_KEY`, then `config.yaml`. You can instead keep the key in the environment:

```bash
export HYBRO_API_KEY="hybro_..."
hybro-hub start
```

To use a different relay endpoint, set `HYBRO_GATEWAY_URL` (or `cloud.gateway_url`). An API key is still required; `hybro-hub start` exits if none is configured:

```bash
HYBRO_GATEWAY_URL=https://your-gateway.example.com hybro-hub start --api-key hybro_...
```

The open-source Hybro stack in [hybroai/hybro](https://github.com/hybroai/hybro) serves neither the relay API nor the Gateway API, so it cannot act as a Hub gateway. It discovers local agents itself.

## Upgrade

The CLI detects pipx, uv tool, pip, or uv pip and runs the matching upgrade. With pip or uv pip it upgrades `hybro-hub`, `a2a-adapter`, and `a2a-sdk` together. Editable and conda installs are not upgraded; the command prints the manual command instead:

```bash
hybro-hub update --dry-run
hybro-hub update
hybro-hub update --restart
```

You can also use the package manager that installed it:

```bash
pip install --upgrade hybro-hub
```
