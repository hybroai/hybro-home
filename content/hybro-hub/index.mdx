# Hybro Hub

Hybro Hub is a lightweight background daemon that connects A2A agents on your machine to [hybro.ai](https://hybro.ai). It discovers local agents, keeps their status synchronized, and relays tasks over an outbound-only connection.

The same package also includes `HybroGateway`, an async Python client for discovering and calling cloud agents programmatically.

> Hybro Hub and `HybroGateway` work only with the hosted service at [hybro.ai](https://hybro.ai). The self-hosted, open-source [Hybro](/docs/hybro) platform does not use the Hub: it discovers agents on your machine itself.

## Key properties

| Capability | Description |
| --- | --- |
| **Outbound-only relay** | No inbound firewall rule or public local-agent URL is required |
| **A2A discovery** | Probes `/.well-known/agent-card.json` and the legacy `/.well-known/agent.json` path |
| **Local-agent launchers** | Starts Ollama, OpenClaw, n8n, Claude Code, Codex, and Hermes adapters |
| **Health monitoring** | Periodically checks agents and synchronizes availability |
| **Task handling** | Supports streaming, input-required tasks, and cancellation |
| **Offline resilience** | Persists failed publish events to disk and retries them |
| **Privacy classification** | Detects PII and custom patterns; currently logs warnings without blocking |

## Quick start

```bash
pip install hybro-hub
hybro-hub start --api-key hybro_your_key_here
hybro-hub agent start ollama --model llama3.2
```

`hybro-hub agent start` stays in the foreground, so run it in a separate terminal. The running daemon picks up the new agent on its next re-sync (within about two minutes), or right away after `hybro-hub restart`. Then open [hybro.ai](https://hybro.ai) and use the local agent alongside cloud agents.

The daemon runs in the background by default. Use:

```bash
hybro-hub status
hybro-hub agents
hybro-hub stop
```

`hybro-hub agents` runs its own local scan, so it works even when the daemon is stopped.

## One package, two uses

- **Hub daemon:** `hybro-hub start` connects local agents to the Hybro relay.
- **Gateway client:** `from hybro_hub import HybroGateway` calls cloud agents from Python.
