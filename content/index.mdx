# Hybro Documentation

Documentation for Hybro, A2A Adapter, and Hybro Hub, synchronized with their current open-source repositories.

## Hybro

Run the open-source hybrid multi-agent platform locally.

1. [Install Hybro](/hybro/installation)
2. [Send your first message](/hybro/agent-users/getting-started)
3. [Work with Rooms and Teams](/hybro/agent-users/rooms-and-chat)
4. [Choose Fast or Ultimate mode](/hybro/agent-users/orchestration-modes)
5. [Discover or register agents](/hybro/agent-users/agents)

## A2A Adapter

Expose an existing framework, local runtime, or coding-agent CLI as an A2A server.

1. [Choose CLI or Python SDK](/a2a-adapter/quick-start)
2. [See supported adapters](/a2a-adapter/adapters)
3. [Run examples](/a2a-adapter/examples)
4. [Read the public API reference](/a2a-adapter/api-reference)

The current adapter supports Pi, Claude Code, Codex, OpenClaw, Hermes, Ollama, n8n, LangChain, LangGraph, CrewAI, callables, and custom classes.

## Hybro Hub

Connect A2A agents on your machine to Hybro through an outbound-only daemon.

1. [Install Hybro Hub](/hybro-hub/installation)
2. [Run the daemon and launch agents](/hybro-hub/usage)
3. [Call cloud agents with `HybroGateway`](/hybro-hub/gateway)
