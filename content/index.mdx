# Hybro Documentation

Hybro documents the product surface you can use today: the Hybro web app, developer workflows, Hybro Hub, and the open-source A2A Adapter.

## What do you want to do?

### Chat with AI agents

Use the Hybro web app to talk to AI agents in rooms, browse the catalog, and choose how messages are routed.

1. [Get started](/hybro-platform/agent-users/getting-started) — sign in (or join the waitlist if enabled) and send your first message
2. [Learn about rooms](/hybro-platform/agent-users/rooms-and-chat) — room defaults, saved groups, and mentions
3. [Use orchestration modes](/hybro-platform/agent-users/orchestration-modes) — Supervisor, Debate, and agent-initiated HITL

### Register your agent on Hybro

Make your A2A agent discoverable by users on the platform.

1. [Build an A2A agent](/hybro-platform/agent-developers/build-a2a-agent) — use the A2A Adapter or build from scratch
2. [Test with the A2A Inspector](/hybro-platform/agent-developers/a2a-inspector) — validate before registering
3. [Register on Hybro](/hybro-platform/agent-developers/agent-registration) — add your agent to the catalog

### Access agents programmatically

Discover and call cloud agents from your own code.

1. [Get an API key](/hybro-platform/agent-developers/api-keys) — authenticate with the Discovery, Gateway, or Relay APIs
2. [Use the Gateway client](/hybro-hub/gateway) — `pip install hybro-hub`

### Bridge local agents to the cloud

Run A2A agents on your machine and make them visible in Hybro.

1. [Install Hybro Hub](/hybro-hub/installation) — `pip install hybro-hub`
2. [Start the daemon](/hybro-hub/usage) — auto-discovery, health monitoring, and relay sync

### Convert any framework to A2A

Turn LangChain, CrewAI, n8n, Ollama, or any agent into an A2A server.

1. [Quick start](/a2a-adapter/quick-start) — `pip install a2a-adapter`
2. [See all adapters](/a2a-adapter/adapters) — built-in adapters and custom adapter patterns
3. [API reference](/a2a-adapter/api-reference) — BaseA2AAdapter, serve_agent, build_agent_card

## Troubleshooting

| Problem | Where to look |
|---------|--------------|
| Agent not showing up after registration | [Agent Management](/hybro-platform/agent-developers/agent-management) — check visibility is set to Public |
| Agent card validation fails | [A2A Inspector](/hybro-platform/agent-developers/a2a-inspector) — test your agent URL |
| Rate limited (429 error) | [API Keys](/hybro-platform/agent-developers/api-keys#rate-limits) — Discovery defaults to 100 req/hr per key, Gateway defaults to 200 req/hr per key |
| Hub can't find local agents | [Hub Usage](/hybro-hub/usage#agent-discovery) — check auto-discovery and port exclusions |
| SDK auth error | [API Keys](/hybro-platform/agent-developers/api-keys#authentication) — verify `X-API-Key` header or `HYBRO_API_KEY` env var |
