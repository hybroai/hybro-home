# Hybro Documentation

Documentation for Hybro, A2A Adapter, and Hybro Hub, synchronized with their current open-source repositories.

## Hybro

Run the open-source hybrid multi-agent platform locally.

1. [Install Hybro](/docs/hybro/installation)
2. [Configure models and credentials](/docs/hybro/configuration)
3. [Send your first message](/docs/hybro/agent-users/getting-started)
4. [Work with Rooms and Teams](/docs/hybro/agent-users/rooms-and-chat)
5. [Choose Fast or Ultimate mode](/docs/hybro/agent-users/orchestration-modes)
6. [Discover or register agents](/docs/hybro/agent-users/agents)

## A2A Adapter

Expose an existing framework, local runtime, or coding-agent CLI as an A2A server.

1. [Choose CLI or Python SDK](/docs/a2a-adapter/quick-start)
2. [See supported adapters](/docs/a2a-adapter/adapters)
3. [Run examples](/docs/a2a-adapter/examples)
4. [Read the public API reference](/docs/a2a-adapter/api-reference)

The current adapter supports Pi, Claude Code, Codex, OpenClaw, Hermes, Ollama, n8n, LangChain, LangGraph, CrewAI, callables, and custom classes.

## Hybro Hub

Connect local A2A agents to the hosted Hybro network through an outbound-only daemon, and call cloud agents from Python.

1. [Install Hybro Hub](/docs/hybro-hub/installation)
2. [Run the daemon and launch agents](/docs/hybro-hub/usage)
3. [Call cloud agents with `HybroGateway`](/docs/hybro-hub/gateway)
