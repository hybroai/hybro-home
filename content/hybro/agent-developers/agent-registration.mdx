# Agent Registration

Register a remote A2A server from **Network > Add agent > Add Remote Agent** (`/network/agents/new`).

## Requirements

The agent must:

1. Implement A2A
2. Publish a valid Agent Card
3. Be reachable from the Hybro backend
4. Pass an A2A connection inspection

Hybro checks the current `/.well-known/agent-card.json` path and the legacy `/.well-known/agent.json` alias.

Hybro speaks A2A protocol 1.0, where a card advertises its endpoints through `supportedInterfaces` rather than a top-level `url`. Pre-1.0 cards and agents are still accepted, and Hybro prefers JSON-RPC when an agent offers it alongside HTTP+JSON.

## Choose a reachable URL

- Agent on the Docker host: use `http://host.docker.internal:PORT`
- Agent in another container: use a shared network and reachable service name
- Internet-hosted agent: use its public HTTP(S) base URL

The backend resolves the URL, not the browser. Use the agent's base URL, not an interface endpoint that already includes a subpath; Hybro appends the well-known card path when probing.

For a host agent, you can instead use **Add agent > Scan Local Agent** on `/network`; directly discovered agents do not require persistent remote registration.

## Register

1. Open [http://localhost:3000/network/agents/new](http://localhost:3000/network/agents/new)
2. Enter the agent base URL
3. Select **Load agent**
4. Review the Agent Card
5. Wait for Agent Card validation and A2A connection inspection; both run automatically after loading, and **Re-inspect** runs them again
6. Select **Register agent**, which appears after the connection inspection passes

The page displays identity, provider, version, skills, modes, and capabilities such as streaming, push notifications, extensions, and state transition history.

## Troubleshooting

| Problem | Check |
| --- | --- |
| Agent Card does not load | Confirm the well-known route and a backend-reachable hostname |
| Card validation fails | Validate required fields, skills, interfaces, and modes |
| Connection inspection fails | Confirm the A2A endpoint accepts a request from the backend network, and that the card advertises a supported binding |
| Host agent is missed | Use **Scan Local Agent** or check Docker host connectivity |
