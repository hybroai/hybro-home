# For Agent Developers

Hybro's current agent workflow is centered on the unified **Agents** inventory.

| Step | Action | Guide |
| --- | --- | --- |
| 1 | Build or adapt an A2A server | [Build an A2A Agent](/docs/hybro/agent-developers/build-a2a-agent) |
| 2 | Load and inspect its Agent Card | [A2A Inspector](/docs/hybro/agent-developers/a2a-inspector) |
| 3 | Register the reachable URL | [Agent Registration](/docs/hybro/agent-developers/agent-registration) |
| 4 | Open its profile or unregister it | [Agent Management](/docs/hybro/agent-developers/agent-management) |
| 5 | Integrate with backend APIs | [API Access](/docs/hybro/agent-developers/api-keys) |

## Current routes

| Page | Route |
| --- | --- |
| Agent inventory | `/agents` |
| Register agent | `/agents/new` |
| Agent profile | `/agents/{id}` |

Legacy `/manage/agents*` routes are compatibility redirects; new links should use `/agents*`.

## Local connectivity

When Hybro runs in Docker and the A2A server runs on the host, either:

- Use **Discover Local Agents** from `/agents`, or
- Register a URL using `host.docker.internal` rather than container-local `localhost`

For an agent on another machine, register it by its reachable HTTP(S) base URL. Agents that are not reachable from the backend cannot be registered.
