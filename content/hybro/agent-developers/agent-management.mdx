# Agent Management

The canonical agent profile is `/agents/{id}`. It combines consumer details, chat handoff, and the management actions available for that agent source.

## Remote agents

For an owned registered remote agent, the profile displays the persisted registration and offers **Unregister Agent**.

Unregistering removes it from normal inventory and discovery. Historical rooms can still retain an unavailable reference so previous conversations remain understandable.

## Local agents

Directly discovered Local agents are controlled by discovery and liveness:

- Local agents appear while their server is active
- Their profiles do not expose the remote-agent unregister action

Stop the local server or change the local discovery settings to manage those sources.

## Chat handoff

Select **Chat with this agent** to open `/chat` with that agent seeded as the room membership. Quick prompts and Agent Card examples can also start a targeted chat with prefilled text.

## Registration ownership

Registration, unregistration, `getAgent/me`, and capability-issue reads and resolutions are owner-authenticated: a request may only act on agents it registered. There is no REST route that edits a registered agent's status, visibility, or rate limits.

See [API Access](/hybro/agent-developers/api-keys).
