# Agent Management

The canonical agent profile is `/agents/{id}`. It combines consumer details, chat handoff, and the management actions available for that agent source.

## Remote agents

For an owned registered remote agent, the profile displays the persisted registration and offers **Unregister Agent**.

Unregistering removes it from normal inventory and discovery. Historical rooms can still retain an unavailable reference so previous conversations remain understandable.

## Local and Hub agents

Directly discovered Local agents and Hub-connected agents are controlled by discovery and liveness:

- Local agents appear while their server is active
- Hub agents appear while the agent is active and the Hub is online
- These profiles do not expose the remote-agent unregister action

Stop the local server, change discovery configuration, or update the Hub to manage those sources.

## Chat handoff

Select **Chat with this agent** to open `/chat` with a pending mention. Quick prompts and Agent Card examples can also start a targeted chat.

## Backend management API

The backend still supports owner-authenticated registration management, including status, visibility, and rate-limit fields. The generated OpenAPI document from your running version is the source of truth for these programmatic operations.

See [API Access](/hybro/agent-developers/api-keys).
