# Hybro

[Hybro](https://github.com/hybroai/hybro) is an open-source agent interoperability platform. It connects local and remote A2A agents, runs persistent multi-agent chats, lets other agents and assistants reach yours through sessions, and keeps a person in charge of what matters.

## What Hybro includes

| Capability | Description |
| --- | --- |
| **Overview** | Home dashboard with Sessions, Chats, Agents, and MCP gateway tiles, recent activity, a mini network map, and the most-called agents |
| **Multi-agent chats** | Persistent rooms with files, quoting, cancellation, and human-in-the-loop replies |
| **Execution modes** | Fast direct execution or Ultimate supervisor orchestration |
| **Network workspace** | Topology and structure views of registered remote agents, local agents discovered on the host, and saved subnets |
| **Sessions** | External clients (MCP or REST) open sessions with your agents; you approve or reject agent questions in the app |
| **MCP gateway** | Streamable HTTP MCP server at `http://127.0.0.1:8001/mcp` with agent-network and session tools |
| **A2A registration** | Load, inspect, validate, and register an A2A Agent Card from one flow |
| **Durable runtime** | MongoDB persistence, Redis coordination, SSE delivery, and recovery after reloads |
| **Local-first stack** | Next.js frontend, FastAPI backend, MongoDB, Redis, the MCP adapter, and bundled example agents |
| **CLI-managed configuration** | Configure models and credentials once, then start every service without maintaining environment files |

The open-source frontend uses a built-in local developer identity, so the default Docker deployment does not require account setup. Hybro speaks A2A protocol 1.0 and still accepts agents and cards built for A2A 0.3.

## Quick start

```bash
npm install -g @hybroai/cli
hybro setup
hybro start
```

Or build from a source checkout:

```bash
git clone https://github.com/hybroai/hybro.git
cd hybro
./scripts/hybro setup
./scripts/hybro start --build
```

`setup` chooses a Provider, authentication, and models, and saves them to `~/.hybro/config.json` and `auth.json`. `hybro start` pulls the images published for the CLI's version; `./scripts/hybro start --build` builds them from the checkout. Nothing starts until setup has run.

Open:

- **Hybro app:** [http://localhost:3000](http://localhost:3000)
- **API server:** [http://localhost:8000](http://localhost:8000)
- **API docs:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **MCP server:** `http://127.0.0.1:8001/mcp` (same-host clients only)

See [Installation](/docs/hybro/installation) and [Configuration](/docs/hybro/configuration).
