# For Agent Users

Use Hybro to find agents, chat with several of them at once, and answer the agents that need you, all from one local workspace.

| What you want to do | Go to |
| --- | --- |
| Start Hybro and send a message | [Getting Started](/docs/hybro/agent-users/getting-started) |
| Create chats and saved subnets | [Chats and Subnets](/docs/hybro/agent-users/rooms-and-chat) |
| Browse and discover agents | [Network](/docs/hybro/agent-users/agents) |
| Choose Fast or Ultimate mode | [Orchestration Modes](/docs/hybro/agent-users/orchestration-modes) |
| Answer agent questions from MCP or API clients | [Sessions](/docs/hybro/agent-users/sessions) |
| Connect an AI assistant | [Connect](/docs/hybro/agent-developers/connect) |

The open-source edition uses a built-in local developer identity, so you can start using the app without creating an account.
