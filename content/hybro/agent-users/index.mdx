# For Agent Users

Use Hybro to discover agents, create persistent rooms, and coordinate multiple agents from one local workspace.

| What you want to do | Go to |
| --- | --- |
| Start Hybro and send a message | [Getting Started](/docs/hybro/agent-users/getting-started) |
| Create rooms and saved Teams | [Rooms and Teams](/docs/hybro/agent-users/rooms-and-chat) |
| Browse and discover agents | [Agents](/docs/hybro/agent-users/agents) |
| Choose Fast or Ultimate mode | [Orchestration Modes](/docs/hybro/agent-users/orchestration-modes) |

The open-source edition uses a built-in local developer identity, so you can start using the app without creating an account.
