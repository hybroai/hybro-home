# Getting Started

## 1. Start Hybro

Follow [Installation](/docs/hybro/installation), or run:

```bash
curl -fsSL https://hybro.ai/install.sh | sh
hybro
```

Open [http://localhost:3000](http://localhost:3000). The app opens on **Overview**. The open-source frontend uses the built-in local developer identity, so no sign-in is needed.

## 2. Set up a model provider

Hybro starts without a model provider. Until one is set up, a banner on the Overview and in Chats links to **Settings**, Room Chat is disabled, and the four LLM-backed agents stay inactive; Echo Agent and MCP work at once.

The **Settings** dialog (also under your name at the bottom of the sidebar) opens on **Model provider**, which has three steps:

1. **Provider**: OpenAI, Anthropic, or DeepSeek.
2. **Connect**: for OpenAI, sign in with your ChatGPT account or use an API key; Anthropic and DeepSeek take an API key.
   - **Sign in with ChatGPT** opens chatgpt.com in a new tab. After you approve, that tab says you can close it, and Settings shows **Connected** with the recommended models saved. If the browser is not on the machine running Hybro, the sign-in ends on a `localhost:1455` address that does not load; paste that address into the waiting panel instead.
   - **Check and save** verifies an API key with one small request before saving it. The key is never shown again; **Replace key** sets a new one.
3. **Models**: the text model (the first is recommended) and, with an OpenAI API key, an optional image model and image size. **Save models** applies them.

The provider and models apply without a restart; a new image size applies after `hybro stop` and `hybro`. The status at the top of the section shows **Not set up**, **Waiting for sign-in**, **Connected**, or **ChatGPT sign-in expired**, with **Sign in again** for the last.

## 3. Check available agents

Open **Network** in the sidebar ([http://localhost:3000/network](http://localhost:3000/network)). It shows, in a Topology or Structure view:

- Agents registered with this backend, including the bundled Echo, Weather, Story, Travel Planner, and Image Generator agents
- A2A agents discovered directly on the Docker host

Echo Agent repeats your message and works without a model provider. The others show the reason on their cards while they are inactive; Image Generator Agent also needs an image model. To scan the host now, choose **Add agent > Scan Local Agent**.

## 4. Start a chat

Open **Chats** in the sidebar, select **New chat** on Overview, or go to [http://localhost:3000/chat](http://localhost:3000/chat).

**Featured Use Cases** cards create or reuse a preset subnet with the agents they need, select it, and prefill the composer. Before sending, you can also:

- Use **All agents** as the candidate scope
- Choose **Room agents** or a saved **subnet**
- Type `@` to target one or more agents
- Select **Fast** or **Ultimate** mode
- Attach files

## 5. Send a message

Hybro creates a persistent room, stores the message and attachments, schedules the selected execution mode, and streams progress into the timeline.

Each turn renders a Trace that shows agent calls, tool activity, and any question waiting for your answer, followed by the final answer and one card per delegated agent. The chat appears in the **History** column next to the sidebar. Active processing can be restored after a reload, and the room timeline supports artifacts, cancellation, and human-in-the-loop questions.
