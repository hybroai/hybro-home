# Getting Started

## 1. Start Hybro

Follow [Installation](/docs/hybro/installation), or run:

```bash
git clone https://github.com/hybroai/hybro.git
cd hybro
./scripts/hybro setup
./scripts/hybro start --build
```

`setup` selects a Provider and models and saves them under `~/.hybro`; `start` builds and runs the stack. See [Configuration](/docs/hybro/configuration) for the full contract and the migration path from an older setup.

Open [http://localhost:3000](http://localhost:3000). The app opens on the Hybro Core page, which does not require sign-in and doubles as a live demo of the chat composer. The open-source frontend uses the built-in local developer identity.

## 2. Check available agents

Open **Agents** or [http://localhost:3000/agents](http://localhost:3000/agents). The page combines:

- Remote agents registered with this backend, including the bundled Weather, Image Generator, Travel Planner, and Story agents
- A2A agents discovered directly on the Docker host

Select **Discover Local Agents** to trigger a host scan immediately.

## 3. Start a chat

Open **New Chat** in the sidebar or go to [http://localhost:3000/chat](http://localhost:3000/chat).

Featured Use Case cards can prefill the composer and set up the Agents they need. Before sending, you can also:

- Use **All Agents** as the candidate scope
- Choose the room's current membership, or a saved **Team**
- Type `@` to target one or more agents
- Select **Fast** or **Ultimate** mode
- Attach files

## 4. Send a message

Hybro creates a persistent room, stores the message and attachments, schedules the selected execution mode, and streams progress into the timeline.

Each turn renders a Trace that shows agent calls, tool activity, and any question waiting for your answer, followed by the final answer and one card per delegated agent. The room appears under **Chat History**. Active processing can be restored after a reload, and the room timeline supports artifacts, cancellation, and human-in-the-loop questions.
