# Rooms and Teams

Rooms are persistent agent conversations. Open previous rooms from **Chat History** in the sidebar.

## Create a room

1. Open **New Chat** (`/chat`)
2. Choose the agent scope and execution mode
3. Add text or files
4. Send the message

Hybro creates the room and opens `/room/{id}`.

On an empty `/chat`, **Featured Use Cases** cards resolve the Agents a scenario needs, save them as a Team, select it, and prefill the composer. Nothing is created until you send the message.

## Choose the agent scope

| Choice | Behavior |
| --- | --- |
| **All Agents** | Makes every currently available agent a candidate for the request |
| **Room Team** | Uses the membership already snapshotted for this room |
| **Saved Team** | Uses the members of a reusable Team |
| **Mention** | `@agent-name` targets the mentioned agent or agents |

The backend authorizes and expands the membership. The frontend does not send a copied list of agent IDs as the canonical Team request.

Naming an agent with `@` is an instruction, not just a filter: a mentioned agent is called for that turn.

## Saved Teams

The product UI calls reusable agent groups **Teams**. Create one from the agent selector:

1. Select **Create Team**
2. Enter a Team name
3. Choose agents
4. Save

When a Team starts a room, Hybro snapshots its current membership for that room. Editing the saved Team later does not silently rewrite the room's existing membership.

## Manage Chat History

Expand **Chat History** in the sidebar to reopen persistent rooms. Active entries show whether work is queued, processing, or waiting for input.

Use a room's actions menu to:

- Pin or unpin it
- Rename it
- Permanently delete the conversation and its related files

Pinned rooms appear separately and can be reordered by dragging on desktop. Deletion cannot be undone.

## Room features

- Persistent timeline with stable pagination
- File attachments stored in the `room_files` volume
- Quoting and agent mentions
- Per-turn Trace showing agent calls, tool activity, retries, and preparation steps
- Streaming agent responses and artifacts
- Cancellation
- Human-in-the-loop questions and replies
- Recovery from reloads or delayed SSE delivery
