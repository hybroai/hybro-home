# Chats and Subnets

Chats are persistent agent conversations, also called rooms. Open previous chats from the **History** column shown beside the sidebar on the Chats and room pages (inside the navigation sheet on mobile).

## Start a chat

1. Open **Chats** (`/chat`) or select **New chat**
2. Choose the agent scope and execution mode
3. Add text or files
4. Send the message

Hybro creates the room and opens `/room/{id}`.

On an empty `/chat`, **Featured Use Cases** cards resolve the agents a scenario needs, save them as a preset subnet (or reuse it if it already exists), select it, and prefill the composer. Nothing is sent until you send the message.

## Choose the agent scope

| Choice | Behavior |
| --- | --- |
| **All agents** | Makes every currently available agent a candidate for the request |
| **Room agents** | Uses the membership already snapshotted for this room |
| **Saved subnet** | Uses the members of a reusable subnet |
| **Mention** | `@agent-name` targets the mentioned agent or agents |

The backend authorizes and expands the membership. The frontend does not send a copied list of agent IDs as the canonical request.

Naming an agent with `@` is an instruction, not just a filter: a mentioned agent is called for that turn.

## Subnets

The UI calls reusable agent groups **subnets**. Create one from the scope selector (**Create subnet**), from **Network > Create subnet**, or from an agent's **Add to subnet > Create subnet...**. The dialog has a Details step (name and optional description) and a Members step (search and select agents).

Edit or delete subnets from the selector or from the Network details panel. When a subnet starts a chat, Hybro snapshots its membership for that room; later edits do not rewrite existing rooms.

## Manage History

The **History** column has **Pinned** and **Recent** sections. Active entries show whether work is Queued, Running, or Needs input, and the **Chats** sidebar entry shows a badge with the number of chats that need input.

Use a chat's actions menu to:

- Pin or unpin it
- Rename it
- Delete the conversation and its related files (asks for confirmation)

Pinned chats can be reordered by dragging on desktop. Deletion cannot be undone.

## Room features

- Persistent timeline with stable pagination
- File attachments stored in the `room_files` volume
- Quoting and agent mentions
- Per-turn Trace showing agent calls, tool activity, retries, and preparation steps
- Streaming agent responses and artifacts
- Cancellation
- Human-in-the-loop questions and replies
- Recovery from reloads or delayed SSE delivery
