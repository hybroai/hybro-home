# Agents

Hybro's **Agents** page is a unified inventory of A2A agents from three sources.

| Source | Description |
| --- | --- |
| **Remote** | An agent registered from an HTTP(S) A2A URL |
| **Local** | An A2A server discovered directly on the machine hosting Hybro |
| **Hub** | A local or LAN agent connected through Hybro Hub |

## Browse and discover

Open [http://localhost:3000/agents](http://localhost:3000/agents).

You can:

- Search by name, description, skills, or tags
- Select **Discover Local Agents** to scan the Docker host
- Open an agent profile
- Register another remote agent

The inventory refreshes periodically. Local agents appear only while active. Hub agents also require the corresponding Hub to be online.

## Agent profiles

An agent profile can show:

- Name, description, provider, version, and source
- Skills, tags, examples, and quick prompts
- Input/output modes
- Streaming and other A2A capabilities
- Current availability
- A **Chat with this agent** action

Starting a chat from a profile carries a one-time `@mention` draft into `/chat`.

## Availability and removal

Owned remote agents can be unregistered from their profile. Directly discovered Local and Hub agents are discovery-managed, so they do not expose the same unregister action.

Deleted or unavailable agents are hidden from normal inventory results but may remain identifiable in historical room records.
