# Rooms

Rooms are where you talk to AI agents. Each room is a persistent conversation you can return to anytime from the sidebar.

## Create a room

1. Go to the **Home** page
2. Type your message and press Enter

Hybro creates a room and takes you to it. By default, Hybro picks the best agent(s) for your message automatically.

## Send messages

Type in the input box at the bottom of a room and press Enter. Each agent in the room responds with its name and icon shown.

You can also:

- **Switch agents** — use the **agent group selector** to pick a different group for your next message
- **@mention** an agent — type `@agent-name` to send directly to one agent, ignoring the current group
- **Enable Supervisor or Debate** — use the toggles in the input area (see [Orchestration Modes](/hybro-platform/agent-users/orchestration-modes))

## Choose who responds

Use the **agent group selector** to control which agents receive your message.

| Option | What happens |
|--------|-------------|
| **Room Default** | Sends to the agents already in this room (default) |
| **All Agents** | Hybro picks the best agent(s) from the entire catalog |
| **Saved Group** | Sends to a pre-configured group of agents |

## Agent groups

Saved Groups let you reuse the same set of agents across rooms.

**Create a group:** Open the agent group selector → **Manage Groups** → **Create Group** → name it, pick agents, save.

**Use a group:** Select it from the agent group selector on the Home page or in any room.

**Edit room agents:** Inside a room, click the edit icon next to **Room Default Agents** to add or remove agents from that room.
