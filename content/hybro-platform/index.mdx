## Key Concepts

| Concept                 | Description                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------- |
| **Room**                | A conversation space where you chat with one or more agents                         |
| **Room Default Agents** | The room-scoped snapshot of agents used by the room when you send with Room Default |
| **Agent Group**         | A reusable, saved collection of agents                                              |
| **Target Mode**         | How messages are routed — Room Default, All Agents, or Saved Group                  |
| **Mentions**            | `@agent-name` syntax to direct a message to specific agents                         |
