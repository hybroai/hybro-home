# Examples

Runnable examples live in the [a2a-adapter repository](https://github.com/hybroai/a2a-adapter/tree/main/examples).

## Setup

```bash
git clone https://github.com/hybroai/a2a-adapter.git
cd a2a-adapter
pip install -r examples/requirements.txt
```

`examples/requirements.txt` installs `a2a-adapter[all]` and `langchain-openai`, which the LangChain example uses.

Framework-specific extras are also available:

```bash
pip install 'a2a-adapter[crewai]'
pip install 'a2a-adapter[langchain]'
pip install 'a2a-adapter[langgraph]'
```

## CLI examples

No Python file is required for the supported CLI-backed agents:

```bash
a2a-adapter pi --port 9012
a2a-adapter codex --port 9011
a2a-adapter claude --port 9010
a2a-adapter openclaw --port 9008
```

Hermes is currently available through the Python SDK, not the thin CLI.

Run a server in one terminal:

```bash
python examples/quickstart.py callable
```

Then test it from another:

```bash
python examples/single_agent_client.py
```

`single_agent_client.py` sends to `http://localhost:9000`; edit `agent_url` to test a server on another port.

The Claude Code, Codex, and Pi examples take an optional project path:

```bash
python examples/claude_code_agent.py /path/to/project
```

## Minimal callable

```python
from a2a_adapter import CallableAdapter, serve_agent

async def echo(inputs):
    return f"Echo: {inputs['message']}"

adapter = CallableAdapter(func=echo, name="Echo")
serve_agent(adapter, port=9000)
```

## Config-driven deployment

```python
from a2a_adapter import load_adapter, serve_agent

adapter = load_adapter({
    "adapter": "n8n",
    "webhook_url": "http://localhost:5678/webhook/agent",
    "name": "Workflow Agent",
})
serve_agent(adapter, port=9000)
```

## Prerequisites by integration

- **OpenAI-backed examples:** set `OPENAI_API_KEY`
- **Claude Code:** install `@anthropic-ai/claude-code` and sign in, or set `ANTHROPIC_API_KEY`. Set `A2A_CLAUDE_SKIP_PERMISSIONS=1` only in a trusted sandbox
- **Codex:** install `@openai/codex` and sign in. `A2A_CODEX_BYPASS_APPROVALS=1` and `A2A_CODEX_SKIP_GIT_CHECK=1` are available for trusted sandboxes
- **Pi:** install Pi, or set `A2A_PI_COMMAND` (read by the CLI and `pi_agent.py`). `pi_agent.py` also reads `A2A_PI_SESSION_ID`
- **Ollama:** start Ollama and pull the configured model
- **Hermes:** put a Hermes Agent checkout on `PYTHONPATH` and run `hermes setup`
