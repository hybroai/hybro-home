# Configuration

Adapter-specific configuration options.

## N8n Adapter

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `webhook_url` | Yes | — | n8n webhook URL (e.g. `https://n8n.example.com/webhook/agent`) |
| `timeout` | No | `30` | Request timeout in seconds |
| `headers` | No | — | Extra HTTP headers (e.g. `{"Authorization": "Bearer token"}`) |

```python
{
    "adapter": "n8n",
    "webhook_url": "https://n8n.example.com/webhook/agent",
    "timeout": 30,
    "headers": {"Authorization": "Bearer token"}
}
```

## CrewAI Adapter

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `crew` | Yes | — | CrewAI Crew instance |
| `inputs_key` | No | `"inputs"` | Key for crew inputs |

```python
{
    "adapter": "crewai",
    "crew": crew_instance,
    "inputs_key": "inputs"
}
```

## LangChain Adapter

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `runnable` | Yes | — | Any LangChain Runnable |
| `input_key` | No | `"input"` | Key for runnable input |
| `output_key` | No | `None` | Optional key to extract from output |

```python
{
    "adapter": "langchain",
    "runnable": chain,
    "input_key": "input",
    "output_key": None
}
```

## LangGraph Adapter

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `graph` | Yes | — | Compiled graph from `StateGraph.compile()` |
| `input_key` | No | `"messages"` (chat) or `"input"` | Key for graph input |
| `output_key` | No | `None` | Key from final state to use as output |
| `async_mode` | No | `False` | Enable async task execution |
| `async_timeout` | No | `300` | Timeout for async mode (seconds) |

```python
{
    "adapter": "langgraph",
    "graph": compiled_graph,
    "input_key": "messages",
    "output_key": None,
    "async_mode": False,
    "async_timeout": 300
}
```

## Callable Adapter

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `callable` | Yes | — | Async function `(inputs: dict) -> ...` |
| `supports_streaming` | No | `False` | Whether the callable supports streaming |

```python
{
    "adapter": "callable",
    "callable": async_function,
    "supports_streaming": False
}
```

## Serving Options

`serve_agent()` accepts:

- `agent_card` — A2A `AgentCard` (name, description, etc.)
- `adapter` — Adapter instance from `load_a2a_agent()`
- `host` — Default `"0.0.0.0"`
- `port` — Default `9000`
- `**kwargs` — Passed to `uvicorn.run()` (e.g. `log_level="debug"`)
