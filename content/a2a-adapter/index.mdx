# A2A Adapter

**Expose an AI agent as an A2A Protocol server with either a CLI command or a few lines of Python.**

- [PyPI Package](https://pypi.org/project/a2a-adapter/)
- [GitHub Repository](https://github.com/hybroai/a2a-adapter)

The current `0.2.x` release uses `a2a-sdk` 1.x and supports A2A 1.0 while retaining compatibility routes for older clients.

## Installation

```bash
pip install a2a-adapter
```

Python 3.11 or newer is required.

## CLI: expose an installed coding agent

Run the command from the project directory the agent should work in:

```bash
a2a-adapter pi --port 9012
a2a-adapter codex --port 9011
a2a-adapter claude --port 9010
a2a-adapter openclaw --port 9008
```

Use `--cwd /path/to/project` to select another directory. Server options go before `--`; native agent options go after it:

```bash
a2a-adapter pi --port 9012 -- --model <model> --thinking high
a2a-adapter codex --port 9011 -- --model <model> --sandbox workspace-write
```

Run `a2a-adapter -help` or `a2a-adapter <agent> -help` for the complete command reference.

## Python SDK: wrap an application or framework

```python
from a2a_adapter import CallableAdapter, serve_agent

async def echo(inputs):
    return f"Echo: {inputs['message']}"

adapter = CallableAdapter(func=echo, name="Echo")
serve_agent(adapter, port=9000)
```

The generated Agent Card is available at:

```text
http://localhost:9000/.well-known/agent-card.json
```

The legacy `/.well-known/agent.json` alias is also served.

## Supported adapters

| Framework or agent | Adapter | Streaming |
| --- | --- | ---: |
| Claude Code | `ClaudeCodeAdapter` | Yes |
| Codex | `CodexAdapter` | No |
| Pi | `PiAdapter` | Yes |
| OpenClaw | `OpenClawAdapter` | No |
| Hermes Agent | `HermesAdapter` | Yes |
| n8n | `N8nAdapter` | No |
| LangGraph | `LangGraphAdapter` | Yes |
| LangChain | `LangChainAdapter` | Yes |
| CrewAI | `CrewAIAdapter` | No |
| Ollama | `OllamaAdapter` | Yes |
| Python callable | `CallableAdapter` | Optional |
| Custom class | `BaseA2AAdapter` | Optional |

See [Adapters](/docs/a2a-adapter/adapters) for setup notes and [API Reference](/docs/a2a-adapter/api-reference) for the public Python surface.

## What the adapter handles

- A2A Agent Card generation
- JSON-RPC and REST routes from the official A2A SDK
- Task lifecycle and SSE streaming
- Push-notification configuration
- A2A 1.0 and v0.3 compatibility handling
- Adapter cleanup when the server shuts down
