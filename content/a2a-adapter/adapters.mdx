# Adapters

The package supports CLI-backed coding agents, Python frameworks, local runtimes, webhooks, and custom callables. For exact constructor signatures, see the [source integrations](https://github.com/hybroai/a2a-adapter/tree/main/a2a_adapter/integrations).

## CLI-backed agents

### PiAdapter

Runs one persistent Pi RPC process and durable session. It supports streaming, context binding, graceful abort, and a configurable Pi command.

```python
from a2a_adapter import PiAdapter, serve_agent

adapter = PiAdapter(
    working_dir="/path/to/project",
    model="<model>",
    name="Pi Agent",
)
serve_agent(adapter, port=9012)
```

For the common case, use `a2a-adapter pi --port 9012`.

### ClaudeCodeAdapter

Runs Claude Code in a project directory with streaming and multi-turn session support.

```python
from a2a_adapter import ClaudeCodeAdapter, serve_agent

adapter = ClaudeCodeAdapter(
    working_dir="/path/to/project",
    name="Claude Code Agent",
)
serve_agent(adapter, port=9010)
```

### CodexAdapter

Runs Codex CLI with multi-turn session support. Responses are delivered after the command completes.

```python
from a2a_adapter import CodexAdapter, serve_agent

adapter = CodexAdapter(
    working_dir="/path/to/project",
    name="Codex Agent",
)
serve_agent(adapter, port=9011)
```

### OpenClawAdapter

Runs OpenClaw as a subprocess and supports session IDs, agent IDs, thinking levels, cancellation, custom environment variables, and a working directory.

```python
from a2a_adapter import OpenClawAdapter, serve_agent

adapter = OpenClawAdapter(
    thinking="low",
    working_directory="/path/to/project",
    name="OpenClaw Agent",
)
serve_agent(adapter, port=9008)
```

## Local and hosted runtimes

### HermesAdapter

Wraps [Hermes Agent](https://github.com/NousResearch/hermes-agent) with streaming, tool use, persistent memory, and per-session request serialization.

```python
from a2a_adapter import HermesAdapter, serve_agent

adapter = HermesAdapter(
    model="anthropic/claude-sonnet-4",
    enabled_toolsets=["hermes-cli"],
    name="Hermes Agent",
)
serve_agent(adapter, port=9010)
```

A Hermes Agent checkout must be available on `PYTHONPATH`; run `hermes setup` first.

### OllamaAdapter

Connects to Ollama's `/api/chat` endpoint with NDJSON streaming.

```python
from a2a_adapter import OllamaAdapter, OllamaClient, serve_agent

client = OllamaClient(
    model="llama3.2",
    base_url="http://localhost:11434",
    system_prompt="You are a helpful assistant",
)
adapter = OllamaAdapter(client=client, name="Local LLM")
serve_agent(adapter, port=10010)
```

`OllamaAdapter(model="llama3.2")` remains available as a convenience form.

### N8nAdapter

Calls an n8n webhook. It supports retries, headers, payload templates, input mapping, and multimodal file/image payloads.

```python
from a2a_adapter import N8nAdapter, serve_agent

adapter = N8nAdapter(
    webhook_url="http://localhost:5678/webhook/agent",
    message_field="message",
    name="n8n Agent",
)
serve_agent(adapter, port=9000)
```

## Python frameworks

### LangChainAdapter

Wraps any LangChain `Runnable`. Streaming is available through `.astream()`.

```python
adapter = LangChainAdapter(
    runnable=chain,
    input_key="input",
    output_key=None,
    name="LangChain Agent",
)
```

### LangGraphAdapter

Wraps a compiled LangGraph graph and can stream graph output.

```python
adapter = LangGraphAdapter(
    graph=compiled_graph,
    input_key="messages",
    output_key="output",
    name="Workflow Agent",
)
```

### CrewAIAdapter

Wraps a CrewAI `Crew` and executes it asynchronously with a synchronous fallback.

```python
adapter = CrewAIAdapter(
    crew=crew,
    inputs_key="inputs",
    name="Research Crew",
)
```

## Callables and custom adapters

### CallableAdapter

```python
from a2a_adapter import CallableAdapter

async def echo(inputs):
    return f"Echo: {inputs['message']}"

adapter = CallableAdapter(func=echo, streaming=False, name="Echo")
```

Set `streaming=True` when `func` is an async generator.

### BaseA2AAdapter

Subclass `BaseA2AAdapter` when no built-in integration fits:

```python
from a2a_adapter import AdapterMetadata, BaseA2AAdapter, serve_agent

class MyAdapter(BaseA2AAdapter):
    async def invoke(self, user_input, context_id=None, **kwargs):
        return f"Response to: {user_input}"

    def get_metadata(self):
        return AdapterMetadata(
            name="My Agent",
            description="Custom A2A agent",
        )

serve_agent(MyAdapter(), port=9000)
```

Implement `stream()`, `cancel()`, and `close()` only when the underlying runtime needs them.
