# Adapters

The package supports CLI-backed coding agents, Python frameworks, local runtimes, webhooks, and custom callables. For exact constructor signatures, see the [source integrations](https://github.com/hybroai/a2a-adapter/tree/main/a2a_adapter/integrations).

## CLI-backed agents

### PiAdapter

Runs one persistent Pi RPC process and durable session. It supports streaming, context binding, graceful abort, and a configurable Pi command.

```python
from a2a_adapter import PiAdapter, serve_agent

adapter = PiAdapter(
    working_dir="/path/to/project",
    model="<model>",
    name="Pi Agent",
)
serve_agent(adapter, port=9012)
```

For the common case, use `a2a-adapter pi --port 9012`.

Other options: `pi_command` (an argument list, default `["pi"]`), `cli_args`, `session_id` (default `a2a-pi-agent`), `session_dir` (default `<working_dir>/.a2a-adapter/pi/sessions`), `model_provider`, `timeout` (600 s), `startup_timeout` (30 s), `cancel_grace_timeout` (10 s), and `env_vars`. Pi starts on the first request and handles one turn at a time. With `enforce_single_context=True` (the default), the adapter binds to the first A2A `context_id` and rejects other contexts.

### ClaudeCodeAdapter

Runs Claude Code in a project directory with streaming and multi-turn session support.

```python
from a2a_adapter import ClaudeCodeAdapter, serve_agent

adapter = ClaudeCodeAdapter(
    working_dir="/path/to/project",
    name="Claude Code Agent",
)
serve_agent(adapter, port=9010)
```

Options: `claude_path` (default `claude`), `cli_args`, `timeout` (600 s), `env_vars`, `session_store_path` (default `<working_dir>/.a2a-adapter/claude-code/sessions.json`), and `skip_permissions` (default from `A2A_CLAUDE_SKIP_PERMISSIONS`). The adapter disables Claude's `AskUserQuestion` tool because no user is attached. The default Agent Card name is `Claude Code`.

### CodexAdapter

Runs Codex CLI with multi-turn session support. Responses are delivered after the command completes.

```python
from a2a_adapter import CodexAdapter, serve_agent

adapter = CodexAdapter(
    working_dir="/path/to/project",
    name="Codex Agent",
)
serve_agent(adapter, port=9011)
```

Options: `codex_path` (default `codex`), `cli_args`, `timeout`, `env_vars`, `session_store_path` (default `<working_dir>/.a2a-adapter/codex/sessions.json`), `bypass_approvals` (default from `A2A_CODEX_BYPASS_APPROVALS`), and `skip_git_check` (default from `A2A_CODEX_SKIP_GIT_CHECK`). The default Agent Card name is `Codex`.

### OpenClawAdapter

Runs OpenClaw as a subprocess and supports session IDs, agent IDs, thinking levels, cancellation, custom environment variables, and a working directory.

```python
from a2a_adapter import OpenClawAdapter, serve_agent

adapter = OpenClawAdapter(
    thinking="low",
    working_directory="/path/to/project",
    name="OpenClaw Agent",
)
serve_agent(adapter, port=9008)
```

`thinking` is one of `off`, `minimal`, `low`, `medium`, `high`, or `xhigh` (default `low`). Other options: `session_id` (generated if omitted; each A2A context maps to `<session_id>-<context>`), `agent_id`, `openclaw_path`, `cli_args`, `timeout` (600 s), and `env_vars`. The default Agent Card name is `OpenClaw`.

## Local and hosted runtimes

### HermesAdapter

Wraps [Hermes Agent](https://github.com/NousResearch/hermes-agent) with streaming, tool use, persistent memory, and per-session request serialization.

```python
from a2a_adapter import HermesAdapter, serve_agent

adapter = HermesAdapter(
    model="anthropic/claude-sonnet-4",
    enabled_toolsets=["hermes-cli"],
    name="Hermes Agent",
)
serve_agent(adapter, port=9010)
```

A Hermes Agent checkout must be available on `PYTHONPATH`; run `hermes setup` first. When `model` is omitted, Hermes uses its configured default. `provider` selects the Hermes runtime provider; the Agent Card provider is `agent_provider`. `max_workers` (default 4) sizes the thread pool.

### OllamaAdapter

Connects to Ollama's `/api/chat` endpoint with NDJSON streaming.

```python
from a2a_adapter import OllamaAdapter, OllamaClient, serve_agent

client = OllamaClient(
    model="llama3.2",
    base_url="http://localhost:11434",
    system_prompt="You are a helpful assistant",
)
adapter = OllamaAdapter(client=client, name="Local LLM")
serve_agent(adapter, port=10010)
```

`OllamaAdapter(model="llama3.2")` remains available as a convenience form. `OllamaClient` also accepts `temperature`, `timeout` (120 s), and `keep_alive`. Each request sends the system prompt and the current message only; earlier turns are not carried over.

### N8nAdapter

Calls an n8n webhook. It supports retries, headers, payload templates, input mapping, and multimodal file/image payloads.

```python
from a2a_adapter import N8nAdapter, serve_agent

adapter = N8nAdapter(
    webhook_url="http://localhost:5678/webhook/agent",
    message_field="message",
    name="n8n Agent",
)
serve_agent(adapter, port=9000)
```

File and image payloads need `multimodal_mode=True`, with `file_field`, `image_field`, `encode_files_base64`, `supported_input_types`, and `supported_output_types`. Other options: `timeout` (30 s), `headers`, `max_retries` (2), `backoff` (0.25 s), `payload_template`, `parse_json_input`, `input_mapper`, and `default_inputs`.

## Python frameworks

LangChain, LangGraph, and CrewAI adapters all accept `timeout` (60 s for LangChain and LangGraph, 300 s for CrewAI), `parse_json_input` (a JSON object message is passed through as the input dict), `input_mapper(user_input, context_id)`, and `default_inputs`.

### LangChainAdapter

Wraps any LangChain `Runnable`. Streaming is available through `.astream()`.

```python
adapter = LangChainAdapter(
    runnable=chain,
    input_key="input",
    output_key=None,
    name="LangChain Agent",
)
```

### LangGraphAdapter

Wraps a compiled LangGraph graph and can stream graph output. It also accepts `state_key`. With `input_key="messages"`, the text is wrapped in a `HumanMessage`.

```python
adapter = LangGraphAdapter(
    graph=compiled_graph,
    input_key="messages",
    output_key="output",
    name="Workflow Agent",
)
```

### CrewAIAdapter

Wraps a CrewAI `Crew` and executes it asynchronously with a synchronous fallback.

```python
adapter = CrewAIAdapter(
    crew=crew,
    inputs_key="inputs",
    name="Research Crew",
)
```

## Callables and custom adapters

### CallableAdapter

```python
from a2a_adapter import CallableAdapter

async def echo(inputs):
    return f"Echo: {inputs['message']}"

adapter = CallableAdapter(func=echo, streaming=False, name="Echo")
```

`func` receives `{"message": ..., "context_id": ...}`. A returned dict is reduced to its `response`, `output`, `result`, `answer`, `text`, or `message` key. Set `streaming=True` when `func` is an async generator.

### BaseA2AAdapter

Subclass `BaseA2AAdapter` when no built-in integration fits:

```python
from a2a_adapter import AdapterMetadata, BaseA2AAdapter, serve_agent

class MyAdapter(BaseA2AAdapter):
    async def invoke(self, user_input, context_id=None, **kwargs):
        return f"Response to: {user_input}"

    def get_metadata(self):
        return AdapterMetadata(
            name="My Agent",
            description="Custom A2A agent",
        )

serve_agent(MyAdapter(), port=9000)
```

Implement `stream()`, `cancel()`, and `close()` only when the underlying runtime needs them. Adapters are also async context managers: `async with` calls `close()`.
