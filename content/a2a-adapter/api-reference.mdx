# API Reference

Reference for the public `a2a-adapter` 0.2.x API. The current release depends on `a2a-sdk[http-server]>=1,<2`, and `a2a_adapter.__version__` reports the installed version.

## Server functions

### `serve_agent()`

```python
def serve_agent(
    adapter: BaseA2AAdapter,
    agent_card: AgentCard | None = None,
    host: str = "0.0.0.0",
    port: int = 9000,
    log_level: str = "info",
    **kwargs,
) -> None
```

Builds the A2A app and runs it with Uvicorn. Extra keyword arguments are passed to `uvicorn.run()`. When `agent_card` is omitted, the card URL is `http://<host>:<port>/`, with `0.0.0.0` and `::` shown as `localhost`.

### `to_a2a()`

```python
def to_a2a(
    adapter: BaseA2AAdapter,
    agent_card: AgentCard | None = None,
    task_store: TaskStore | None = None,
    **card_overrides,
) -> Any
```

Returns a Starlette ASGI application. The app exposes A2A 1.0 JSON-RPC and REST routes, enables v0.3 compatibility, and calls `adapter.close()` on shutdown.

If no task store is supplied, `InMemoryTaskStore` is used. JSON-RPC is mounted at `/`, and push-notification configs are kept in memory. Without a `url` override, the generated card advertises `http://localhost:9000/`, so pass `url=` when deploying.

### `build_agent_card()`

```python
def build_agent_card(
    adapter: BaseA2AAdapter,
    **overrides,
) -> AgentCard
```

Builds an A2A 1.0 Agent Card from adapter metadata. Supported overrides include `name`, `description`, `version`, `streaming`, `url`, `provider`, `documentation_url`, and `icon_url`. `streaming=False` does not turn streaming off when `adapter.supports_streaming()` returns `True`. Cards always advertise push notifications. Skill dicts accept `id`, `name`, `description`, `tags`, `examples`, `input_modes`, and `output_modes`.

Generated cards are served at both:

- `/.well-known/agent-card.json`
- `/.well-known/agent.json` (legacy alias)

## `BaseA2AAdapter`

Only `invoke()` is required.

### `invoke()`

```python
async def invoke(
    self,
    user_input: str,
    context_id: str | None = None,
    **kwargs,
) -> str | list[Part]
```

Return text or A2A `Part` objects. The full A2A request context is available as `kwargs.get("context")`.

### `stream()`

```python
async def stream(
    self,
    user_input: str,
    context_id: str | None = None,
    **kwargs,
) -> AsyncIterator[str | Part]
```

Optional. Yield text or `Part` chunks. The executor calls `stream()` when `supports_streaming()` returns `True`, and `invoke()` otherwise.

### `cancel()`

```python
async def cancel(self, context_id: str | None = None, **kwargs) -> None
```

Optional cancellation hook. The executor calls `cancel(context=request_context)`, so read the task with `kwargs["context"].task_id`. Raise `CancelledByAdapterError` from `invoke()` or `stream()` to end a cancelled task without marking it failed.

### `close()`

```python
async def close(self) -> None
```

Optional resource-cleanup hook. The server calls it during shutdown.

### `get_metadata()`

```python
def get_metadata(self) -> AdapterMetadata
```

Returns metadata used to build the Agent Card.

### `supports_streaming()`

```python
def supports_streaming(self) -> bool
```

Detects whether `stream()` is implemented. Override it only when automatic detection is not sufficient.

## `AdapterMetadata`

```python
@dataclass
class AdapterMetadata:
    name: str = ""
    description: str = ""
    version: str = "1.0.0"
    skills: list[dict] = []
    input_modes: list[str] = ["text"]
    output_modes: list[str] = ["text"]
    streaming: bool = False
    provider: dict | None = None
    documentation_url: str | None = None
    icon_url: str | None = None
```

## Loader functions

### `load_adapter()`

```python
def load_adapter(config: dict) -> BaseA2AAdapter
```

Creates an adapter from configuration:

```python
from a2a_adapter import load_adapter

adapter = load_adapter({
    "adapter": "n8n",
    "webhook_url": "http://localhost:5678/webhook/agent",
})
```

Built-in registry names include `n8n`, `crewai`, `langchain`, `langgraph`, `callable`, `openclaw`, `ollama`, `claude-code`, `codex`, `hermes`, and `pi`. Every key other than `adapter` becomes a constructor argument. Registered names take precedence over built-ins, and an unknown name raises `ValueError` listing the available names.

### `register_adapter()`

```python
@register_adapter("my-adapter")
class MyAdapter(BaseA2AAdapter):
    ...
```

Registers a third-party adapter for `load_adapter()`.

## Public adapter exports

The package root lazily exports:

- `N8nAdapter`
- `CrewAIAdapter`
- `LangChainAdapter`
- `LangGraphAdapter`
- `CallableAdapter`
- `OpenClawAdapter`
- `OllamaAdapter` and `OllamaClient`
- `ClaudeCodeAdapter`
- `CodexAdapter`
- `HermesAdapter`
- `PiAdapter`

It also exports `CancelledByAdapterError`.

## Deprecated 0.1 names

The 0.1 compatibility names still exist but are deprecated:

| Deprecated | Replacement |
| --- | --- |
| `BaseAgentAdapter` | `BaseA2AAdapter` |
| `load_a2a_agent()` | `load_adapter()` |
| `build_agent_app()` | `to_a2a()` |
| `*AgentAdapter` classes | shorter `*Adapter` classes |

`load_a2a_agent()` is async and supports only `n8n`, `crewai`, `langchain`, `langgraph`, `callable`, and `openclaw`. The `*AgentAdapter` classes exist only for those six and are imported from `a2a_adapter.integrations`. All deprecated names are slated for removal in 0.3. New code should use the 0.2 API shown above.

## Thin CLI

```text
a2a-adapter {pi,codex,claude,openclaw} [server options] -- [agent options]
```

Server options include `--cwd`, `--host` (default `127.0.0.1`), `--port` (`9000`), `--timeout` (`600`), `--name` (`<Agent> (<folder>)`), `--description`, `--log-level` (`info`), and `--executable`. Pi also supports `--session-id` (default `a2a-pi-agent`) and `--session-dir`; OpenClaw supports `--session-id`, `--agent-id`, and `--thinking` (`off`, `minimal`, `low`, `medium`, `high`, `xhigh`; default `low`). `-h`, `--help`, and `-help` print usage. See [Quick Start](/docs/a2a-adapter/quick-start) for managed flags.

## Environment variables

| Variable | Read by | Effect |
| --- | --- | --- |
| `A2A_CLAUDE_SKIP_PERMISSIONS` | `ClaudeCodeAdapter` | `1` or `true` adds `--dangerously-skip-permissions` |
| `A2A_CODEX_BYPASS_APPROVALS` | `CodexAdapter` | `1` or `true` adds `--dangerously-bypass-approvals-and-sandbox` |
| `A2A_CODEX_SKIP_GIT_CHECK` | `CodexAdapter` | `1` or `true` adds `--skip-git-repo-check` |
| `A2A_PI_COMMAND` | CLI | Pi command when `--executable` is not given, split like a shell command |

Use the permission and approval variables only in trusted, sandboxed environments.
